# GITEX demo script

The goal on the stand: move the visitor from "I have seen threat detection a hundred times" to "wait, this is different, and it is thought through." Do it in under two minutes, live, not on slides.

## The arc

1. **Open with the commodity, honestly.** "Threat detection is solved. The Chinese have had it for years. That is not what this is."
2. **Name the real problem.** False positives across cultures. One line each: loud Polish is not a fight; Mongolian throat singing is a love song, not a war cry.
3. **Show the swarm.** The mock cohort running: edge workers emitting, supervisors filtering, one mind deciding. Point at the three layers.
4. **Show the interpreter deciding.** Run the scenarios live. Same volume, different verdict, because context differs. Read the `cultural_reasoning` line out loud; that is the moment they connect the dots.
5. **Land operational sovereignty.** "No cloud, no uplink, thinks in the van. No external attack surface because there is no external entrance." This is the line the Gulf buyer remembers.
6. **Close on ROI.** "You need the native experts for one year to build it, not forever on every shift."

## What runs live vs what is stated

Be straight about this, because being straight is what separates you from the visionaries on a high.

- **Runs live:** the swarm skeleton and the cultural interpreter, replaying real scenarios, on the workstation. Verdicts and reasoning are generated, not scripted.
- **Stated as roadmap:** the CV and audio perception feeding the edge (commodity, integrated later), and the real RF mesh and edge hardware. The demo feeds the edge with a synthetic event stream on purpose, so the differentiator is what is on screen.

## Optional hardware prop

One real edge node (a Jetson-class board, or a single drone or robot dog) feeding the core live beats any slide. **One** real node, not a fleet. It is a budget decision, not a requirement; the architecture is identical whether the brain sits on the workstation or on the node.

## The one-liner if they ask "do you have it on GitHub"

"Yes. Reference architecture and a running demo, in the open, maturing in public." That is true from day one and it is stronger than claiming an age you cannot prove in the commit history.
